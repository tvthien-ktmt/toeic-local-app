# Project conventions

Copy into the project root as `CLAUDE.md` (or append to `AGENTS.md`), then edit the values below.

## Conventions

- Framework: FastAPI                              # FastAPI | Flask
- Project layout: domain-module (router/service/schemas/models per domain)   # or: blueprint-per-domain for Flask
- Schema/validation library: Pydantic v2           # Pydantic v2 | Marshmallow
- ORM: SQLAlchemy 2.x (async)                       # SQLAlchemy (sync/async) | Flask-SQLAlchemy
- Migrations: Alembic                                # Alembic | Flask-Migrate
- Auth: OAuth2 password flow + JWT
- Max pagination page size: 100
- Logging: standard `logging` module / loguru

## Checklist before opening a PR

- [ ] No `print()` left in application code
- [ ] Every route/view is thin — no DB queries or business logic inline
- [ ] No blocking call inside an `async def` route without `run_in_threadpool` (FastAPI only)
- [ ] Every new endpoint has a request schema with validation
- [ ] Every new endpoint has at least a happy-path + a validation-failure test
- [ ] No hardcoded secret, password, or API key anywhere in the diff
- [ ] Every list/search endpoint has a bounded page size
- [ ] Migration reviewed by hand, not just autogenerated and committed blind
